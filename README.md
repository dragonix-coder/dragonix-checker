# dragonix-checker
Dragonix-Checker is a web-based tool designed to help beginners evaluate crypto tokens before making a purchase. It provides basic token information, a risk assessment, and links to decentralized exchanges (DEXs).  IMPORTANT: THIS WEBSITE IS FOR EDUCATIONAL PURPOSES ONLY. IT DOES NOT HOLD ANY FUNDS, STORE PRIVATE KEYS, OR SIGN TRANSACTIONS.
